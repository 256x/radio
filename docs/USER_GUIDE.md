# Literal Radio User Guide

## Getting Started

1. Launch the app
2. Browse by **Genre** (default), **Country**, **Language**, or **Name**
3. Tap a genre, country, or language to load its stations
4. Tap a station to start playing

The mini player at the bottom stays visible while you browse.

## Browsing

The main screen has four tabs:

| Tab | Contents |
|---|---|
| **Genre** | 22 curated genre presets |
| **Country** | All countries sorted by station count |
| **Language** | All languages sorted by station count |
| **Name** | Search stations by name |

Use the **filter bar** at the bottom to narrow a list by keyword.  
The filter works on the currently visible items — genre names, country names, or station names.

## Playing a Station

Tap any station row to start playback immediately.

- The **mini player** at the bottom shows the station name and current ICY track title.
- Tap the mini player to open the full player screen.
- Tap the **play/pause** button to toggle playback.

The last played station is saved and restored on the next launch.

## Player Screen

The full player shows:

- Station name
- Country code · codec · bitrate · language
- Genre tags
- ICY track title (when broadcast by the station)

Tap the large circle button to play or stop.  
Tap the back arrow to return to the station list.

## Settings

| Setting | Description |
|---|---|
| **Font** | Choose the display font |
| **Font size** | Adjust the base font size |
| **Colors** | Customize background, text, and accent colors |
| **Clear list cache** | Force re-fetch of country and language lists |

### Color picker

Tap **BG**, **Text**, or **Accent** to open the color picker.  
Drag the gradient to pick hue and saturation. The hex value is shown live.  
Tap **Select** to apply.
